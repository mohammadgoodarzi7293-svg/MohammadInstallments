پروژه نهایی «مدیریت اقساط» - محمد گودرزی

این پروژه برای Android Studio آماده شده است.
نام برنامه: مدیریت اقساط
Application ID: com.mohammadgoudarzi.installments
نسخه: 1.0

ساخت APK:
1) Android Studio را نصب و پروژه را با گزینه Open باز کنید.
2) صبر کنید Gradle Sync کامل شود.
3) از منوی Build گزینه Build APK(s) را بزنید.
4) APK در مسیر app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

برای APK انتشار (Release):
Build > Generate Signed Bundle / APK > APK

- محاسبه خودکار تعداد اقساط
- کارمزدهای سالانه مستقل با تاریخ و مبلغ
- تیک اقساط و کارمزدها
- مانده واقعی
- پشتیبان‌گیری و بازیابی
